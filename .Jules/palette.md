## 2025-05-18 - Nested Modal Directory Search UX Pattern
**Learning:** In modal dialogs housing large datasets (such as `PublicDirectory` with 900+ servers), users frequently refine and reset filters. Standard text inputs require tedious manual backspacing on mobile and touch devices. Pairing a prominent leading Search icon with a conditional clear (`X`) button that resets both the query and pagination bounds significantly improves tactile feedback and usability. All icon-only clear buttons within engraved input fields must have an accessible `aria-label` registered with localized translations (English and Myanmar) and maintain keyboard tab/focus states.
**Action:** When adding search or filter inputs within dialogs or trays, wrap the engraved input in a container with a leading indicator icon, provide a conditional clear button with accessible labels in `translations.ts`, and reset pagination slices when cleared.
