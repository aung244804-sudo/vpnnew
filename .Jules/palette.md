## 2026-03-31 - Import Action Feedback Pattern

**Learning:** When users import nodes from a public directory table or list, leaving the action button with the same "+" icon even after disabling creates ambiguity on whether the action succeeded. Transitioning the icon to a Check icon with updated title and aria-label provides immediate visual confirmation and screen reader clarity.
**Action:** For action buttons that perform one-time additions/imports in lists, swap the icon to a checkmark and update accessible text to indicate completed status.
